# Import your settings

When you create a Zulip account using an email address already associated with an account in another Zulip organization, on Zulip Cloud or the same self-hosted Zulip installation, you can import your user settings from an existing account. It’s a convenient way to preserve the user settings that you’ve already customized.

 **Tip:** Settings that may not apply to all organizations, such as custom profile
fields, will not be imported.

The import will include your:

- Name and profile picture.
- Preferences, such as the theme, font size, emoji set, and language you have configured.
- Privacy settings, which include whether you let others see when you are typing or if you have read a message.
- Notification settings, which include default notifications for channels, notifications for topics you follow, and the sound used for audible desktop notifications.

### Import your settings

1. Follow the instructions for joining a Zulip organization.
2. From the dropdown list under **Import settings from an existing Zulip account**,
select the account from which you would like to import your settings.
3. Complete the registration form, and click **Sign up**.
4. *(recommended)* Review your settings.
