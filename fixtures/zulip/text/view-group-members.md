# View group members

User groups can have other groups, roles, and individual users as members.

**Via group card:**

1. Click on a user group mention in a message to open the **group card**. The
group’s members will be listed on the card.
2. If the group has a large number of members, click the **view all** link to
see the rest of the list.

**Via group settings:**

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Group settings**.
3. Click **All groups** in the upper left.
4. Select a user group.
5. Select the **Members** tab on the right.
