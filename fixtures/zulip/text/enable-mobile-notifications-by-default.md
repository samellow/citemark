# Enable mobile notifications by default

**Note:**

This feature is only available to organization owners and administrators.

Users can configure mobile push notifications on a channel by channel basis. For channels where it’s important that everyone stays on top of new messages, such as a channel for urgent announcements, organization administrators can enable mobile notifications by default for new subscribers.

Enabling mobile notifications by default does not change the notification settings of anyone who is already subscribed to the channel, and users can always adjust their notification settings for any channel.

## Enable mobile notifications by default for a channel

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Channel settings**.
3. Click **All** in the upper left.
4. Select a channel.
5. Select the **General** tab on the right.
6. Toggle **Mobile push notifications enabled by default**.
7. Click **Save changes**.

 **Tip:** You can also click on a channel name in the navigation bar at the top of the
app to access its settings, or use the **ellipsis** ()
next to the channel name in the left sidebar.
