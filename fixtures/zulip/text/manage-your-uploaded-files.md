# Manage your uploaded files

Zulip lets you view, sort, filter, download, and delete any files that you have uploaded.

## View a file

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Uploaded files**.
4. Click on the name of a file in the **File** column.

 **Tip:** You can also view a file in the context of the
conversations where it was
mentioned by clicking on a message ID in the **Mentioned in** column.

## Sort your files

You can sort your uploaded files by name, upload date, message ID, and size.

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Uploaded files**.
4. Click on the name of a column to toggle between ascending and descending order.

 **Tip:** You can filter your current view by using the **search box** near the top
right corner of the menu.

## Download a file

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Uploaded files**.
4. In the **Actions** column, click the **download** () icon for the file you want to download.

## Delete a file

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Uploaded files**.
4. In the **Actions** column, click the **delete** () icon for the file you want to remove.
5. Approve by clicking **Delete**. If you delete a file, your message will still
contain a file link, but the link will no longer work.
