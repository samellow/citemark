# Supported browsers

In addition to the mobile and desktop apps, Zulip works great in all major modern web browsers. We recommend pinning the Zulip tab in your favorite browser, so that it’s always easy to find.

For the best user experience, the latest stable versions of the browsers below are recommended.

- Chrome
- Firefox
- Edge
- Safari

## Support policy

The Zulip web app guarantees support for all versions of the major browser engines (Chrome, Firefox, Safari, and Edge) that are sufficiently recent to support the Web Platform Baseline “widely available” category. Users using versions of these browsers that are several years old and do not support the widely available Web Platform Baseline features will receive an in-app warning encouraging them to upgrade.

## Multi protocol chat apps

Zulip is supported by most browser-based multi protocol desktop chat apps like Rambox and Ferdium.

 **Tip:** Choose an app that releases regular security updates. Running
an out-of-date app is a major security risk for your computer.
