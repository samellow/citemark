# Enable moderation requests

**Note:**

This feature is only available to organization owners and administrators.

When moderation requests are enabled, users can report problematic messages. This sends a message to a private channel, where moderators can review the report. To make it easy to see all reports about someone’s behavior and discuss them, there will be a dedicated topic for each user whose messages are reported.

If no channel for moderation requests is configured, users won’t see the option to report a message.

## Enable moderation requests

1. Create a private channel for receiving moderation requests.
2. Click on the **gear** () icon in the upper right corner of the web or desktop app.
3. Select  **Organization settings**.
4. On the left, click **Organization settings**.
5. Under **Automated messages and emails**, configure **Moderation requests**.

## Disable moderation requests

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Organization settings**.
3. On the left, click **Organization settings**.
4. Under **Automated messages and emails**, select **Disable** from the **Moderation requests** dropdown.

## Configure where moderation requests are sent

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Organization settings**.
3. On the left, click **Organization settings**.
4. Under **Automated messages and emails**, configure **Moderation requests**.
