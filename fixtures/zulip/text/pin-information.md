# Pin information

You can use channel descriptions to pin reference information, such as:

- Related channels
- Important topics or messages
- Documentation and other external references

Channel descriptions appear in the navigation bar at the top of the web and desktop apps when you view the channel. You can hover over long channel descriptions with the mouse to view them in full.

You can also pin messages for yourself by starring them.

## Pin information in a channel description

**Desktop/Web:**

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Channel settings**.
3. Click **All** in the upper left.
4. Select a channel.
5. Select the **General** tab on the right.
6. Click the **edit channel name and description** () icon to the right of the
channel name to edit the description.
7. Add any number of links, which you can separate with `|` or another symbol.
  - Channel links: `#**channel name**`
  - Topic links: `#**channel name>topic name**`
  - Message links: `#**channel name>topic name@message ID**`
  - External references: `[link text](URL)`
8. Click **Save changes**.

 **Tip:** You can also click on a channel name in the navigation bar at the top of the
app to access its settings, or use the **ellipsis** ()
next to the channel name in the left sidebar.

 **Tip:** If you aren’t sure how to format a link, copy it from the compose box.
Learn more about linking to content in
Zulip.
