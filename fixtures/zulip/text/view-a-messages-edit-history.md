# View a message's edit history

In Zulip, users who have the appropriate permissions can edit the content of a message they sent, or move messages to a different channel or topic.

Modified messages are tagged as **edited** or **moved**, with the **edited**
indicator taking priority. You can view the history of how a message was
edited and moved, if this is allowed in your organization.

## View a message’s edit history

**Desktop/Web:**

1. Choose a message in the message feed.
2. Click on the message’s **edited** or **moved** label shown next to the
sender’s name, or to the left of the message, to open the edit history. If
you don’t see such a label, the message has not been edited or moved.

 **Keyboard tip:** You can use `Shift` + `H` to view the edit history of the
selected message.
