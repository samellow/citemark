# Open the compose box

The Zulip compose box starts off closed by default, leaving more vertical space for the message feed. There are a number of ways to open the compose box.

## Using the mouse

- Click on any message.
- Click on **Start new conversation**, or **New direct message** at the
bottom of the app.

## Using the keyboard

All replies are to the message in the **blue box**.

- **Reply**: `R` or `Enter`
- **New topic**: `C`
- **New direct message**: `X`

You can move the blue box around using the **arrow keys**, `J`, or
`K`. You can close the compose box using `Esc`, or up/down
arrow if the box is empty.

 **Tip:** Zulip offers handy one-character
keyboard shortcuts for
reading messages. With the compose
box closed, there is no need to use the `Ctrl` key all the time.
