# Zulip help center

Welcome to the help center for Zulip organized team chat! Here, you’ll find up-to-date information on how to use Zulip, or administer a Zulip organization. These pages are designed to guide you as you learn your way around Zulip. They’ll also be your go-to if you’re ever unsure how something works, or if you need to explain it to someone else.

## Mastering Zulip

If you’re using Zulip a lot, it’s worthwhile to learn workflows that will help you spend that time efficiently. Check out:

- Keyboard shortcuts: Mastering a few keyboard
shortcuts (like `N` to go to the next unread topic) can speed up your
workflows.
- Reading strategies: Learn different ways to find what you want to read.
- Mastering the compose box: Learn about everything Zulip’s compose box lets you do.
- Message formatting: Learn about quotes, spoilers, global times, and more.
- Search filters: Learn how to find messages based on where they were sent, whether they contain links or attachments, and other details.
