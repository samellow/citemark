# Restrict message edit history access

**Note:**

This feature is only available to organization owners and administrators.

In Zulip, users who have the appropriate permissions can edit the content of a message they sent, or move messages to a different channel or topic.

Modified messages are tagged as **edited** or **moved**, with the **edited**
indicator taking priority. You can view the history of how a message was
edited and moved, if this is allowed in your organization.

 **Tip:** You can remove the edit history of a single message by
deleting it.

## Restrict message edit history access

You can restrict message edit history access to only show moves, or disable it altogether.

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Organization settings**.
3. On the left, click **Organization permissions**.
4. Under **Message editing**, configure **Allow viewing the history of a
message?**.
5. Click **Save changes**.
