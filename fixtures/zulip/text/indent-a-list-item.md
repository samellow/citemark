# Indent a list item

In Zulip, you can increase or reduce the indentation of a list item using keyboard shortcuts in the compose box.

## How to indent a list item

1. Open the compose box.
2. Place your cursor on a list item, or select multiple list items.
3. Press `Ctrl` + `]` to increase
indentation, or `Ctrl` + `[` to
reduce indentation.

## Examples

- Press `Ctrl` + `]` to increase the
indentation of the current list item.
- Press `Ctrl` + `[` to reduce the
indentation of the current list item.
