# Manage a bot

Zulip lets you manage the properties of any bot for which you are the owner. Organization administrators can also manage any active bot in the organization.

## Manage a bot

**Your bots:**

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Bots**.
4. In the **Actions** column, click the **manage bot** ()
icon for the bot you want to manage.
5. Update bot information as desired, and click **Save changes**.

**All bots:**

**Note:**

This feature is only available to organization owners and administrators.

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Organization settings**.
3. On the left, click **Bots**.
4. In the **Actions** column, click the **manage bot** ()
icon for the bot you want to manage.
5. Update bot information as desired, and click **Save changes**.

## Download `zuliprc` configuration file

### Generic bots

**Your bots:**

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Bots**.
4. In the **Actions** column, click the **download** ()
icon for the bot.

**All bots:**

**Note:**

This feature is only available to organization owners and administrators.

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Organization settings**.
3. On the left, click **Bots**.
4. In the **Actions** column, click the **download** ()
icon for the bot.

### Outgoing and incoming webhook bots

Only the owner of an outgoing or incoming webhook bot has access to its `zuliprc`
configuration file.

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Bots**.
4. In the **Actions** column, click the **manage bot** () icon,
and scroll down to **Zuliprc configuration**.
5. Click the **download** () icon to download the configuration
file, or click **copy** () icon to copy the file contents to your
clipboard.

 **Tip:** You can also click the **download** () icon above the **Bots**
table to download a single configuration file for all of your active **outgoing
webhook** bots.

## Get a bot’s API key

Only a bot’s owner has access to its API key.

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Personal settings**.
3. On the left, click **Bots**.
4. In the **Actions** column, click the **manage bot** () icon,
and scroll down to **API key**.
5. Click the **copy** icon to copy the bot’s API key to your clipboard.

 **Tip:** To generate a new API key, click the **generate new API key** ()
icon.
