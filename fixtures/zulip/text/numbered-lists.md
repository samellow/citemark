# Numbered lists

Zulip supports Markdown formatting for numbered lists.
You can create numbered lists by putting a number followed by a `.` at the start
of each line. Lists are numbered automatically, so you can reorder list items
while editing your message without having to update the numbers. Add two spaces
before the number to create a nested list.

## Create a numbered list

**Via compose box button:**

1. Open the compose box.
2. *(optional)* Select the text you want to format.
3. Click the **numbered list** () icon at the
bottom of the compose box to insert list formatting.
4. Press `Enter` to automatically add a new number to the list.
5. When your list is done, press `Enter` a second time to remove the
number.

 **Tip:** You can also use the **numbered list** () icon
to remove existing list formatting from the current line or selected text.

**Via Markdown:**

1. Open the compose box.
2. Type a number followed by a `.` and some text to start a numbered list.
3. Press `Enter` to automatically add a new number to the list.
4. When your list is done, press `Enter` a second time to remove the
number.

## Examples

### What you type

```
1. numbered lists
1. increment automatically
   1. use nested lists if you like
   3. delete or reorder lines without fixing the numbering
1. one more
   17. lists can start at any number
   18. so you can continue a list after some other text
```
