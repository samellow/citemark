# Manage a user's channel subscriptions

## View a user’s channel subscriptions

**Note**: The list of a user’s **Subscribed channels** will be limited to
channels you can see.

1. Hover over a user’s name in the right sidebar.
2. Click on their avatar or the **ellipsis** () to the right of their name to open their **user card**.
3. Click **View profile**.
4. Select the **Channels** tab.

## Subscribe a user to a channel

**Note:**

You will see the options described only if you have permission to take this action.

**Via channel settings:**

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Channel settings**.
3. Click **All** in the upper left.
4. Select a channel.
5. Select the **Subscribers** tab on the right.
6. Under **Add subscribers**, enter the user’s name or email address. To
subscribe users in bulk, you can copy members from an existing channel or
user group. The typeahead will only include users who
aren’t already subscribed to the channel.
7. Configure **Send notification message to newly subscribed users** as desired.
8. Click **Add**.

 **Tip:** You can also click on a channel name in the navigation bar at the top of the
app to access its settings, or use the **ellipsis** ()
next to the channel name in the left sidebar.

**Via user profile:**

1. Hover over a user’s name in the right sidebar.
2. Click on their avatar or the **ellipsis** () to the right of their name to open their **user card**.
3. Click **View profile**.
4. Select the **Channels** tab.
5. Under **Subscribe user to channels**, select a channel from the
dropdown list. You can start typing to filter channels.
6. Click the **Subscribe** button.

**Via compose box:**

1. Start a message in the channel you want to subscribe someone to, in a new or existing conversation.
2. Mention the user you want to subscribe.
3. Click the **Subscribe them** button on the banner that appears above the
compose box.

 **Tip:** You don’t have to send the message you started composing.

**Mobile:**

Access this feature by following the web app instructions in your mobile device browser.

Implementation of this feature in the mobile app is tracked on GitHub. If you’re interested in this feature, please react to the issue’s description with 👍.

**Note**: Subscribing someone else to a channel sends them an
automated direct message from Notification Bot.

## Unsubscribe a user from a channel

**Note:**

You will see the options described only if you have permission to take this action.

**Via channel settings:**

1. Click on the **gear** () icon in the upper right corner of the web or desktop app.
2. Select  **Channel settings**.
3. Click **All** in the upper left.
4. Select a channel.
5. Select the **Subscribers** tab on the right.
6. Under **Subscribers**, find the user you would like
to unsubscribe from the channel.
7. Click the **unsubscribe** () icon in that row.

 **Tip:** You can also click on a channel name in the navigation bar at the top of the
app to access its settings, or use the **ellipsis** ()
next to the channel name in the left sidebar.

**Via user profile:**

1. Hover over a user’s name in the right sidebar.
2. Click on their avatar or the **ellipsis** () to the right of their name to open their **user card**.
3. Click **View profile**.
4. Select the **Channels** tab.
5. Under **Subscribed channels**, find the channel you would like
to unsubscribe the user from.
6. Click the **unsubscribe** () icon in that row.
